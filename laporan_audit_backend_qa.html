2. Rekonsiliasi Ketidakcocokan Kode & Dokumen Acuan (§4)

4.1 Penghapusan Kamar: Soft-Delete vs prisma.room.delete

Dokumen arsitektur awal mengklaim bahwa penghapusan kamar dilakukan secara soft-delete. Namun, analisis kode aktual pada spesifikasi backend membuktikan hal sebaliknya: 

// backend.md:323-339 — Schema Prisma model Room TIDAK MEMILIKI deletedAt:
model Room {
  id                 String     @id @default(uuid())
  roomNumber         String     @unique @map("room_number")
  ...
  updatedAt          DateTime   @updatedAt @map("updated_at")
  createdAt          DateTime   @default(now()) @map("created_at")
  // TIDAK ADA: deletedAt DateTime?
}

// backend.md:550 — Implementasi RoomsService.remove() adalah HARD DELETE:
async remove(id: string) {
  const activeReservation = await this.prisma.reservation.findFirst({
    where: { roomId: id, actualCheckOutTime: null },
  });
  if (activeReservation) {
    throw new ConflictException('Kamar memiliki riwayat reservasi aktif, tidak dapat dihapus');
  }
  return this.prisma.room.delete({ where: { id } }); // <--- HARD DELETE NYATA
}
Konsekuensi Bahaya Database (Integrity Error): Jika sebuah kamar pernah memiliki riwayat reservasi yang telah selesai (check-out di masa lalu), pemanggilan prisma.room.delete akan langsung melempar PostgreSQL Foreign Key Constraint Violation (Error P2003) karena relasi reservations.roomId terikat ke ID kamar tersebut. Hard delete akan gagal dengan status 500 jika tidak ada cascading rule!

4.2 Ketiadaan PrismaExceptionFilter

Klaim pada laporan sebelumnya bahwa sistem memiliki filter penangkap error Prisma otomatis adalah keliru. Pada backend.md:700-750 dan backend.md:769: 

// main.ts (backend.md:769)
app.useGlobalFilters(new HttpExceptionFilter()); // <--- HANYA HttpExceptionFilter

// http-exception.filter.ts (backend.md:709-711)
const status = exception instanceof HttpException
  ? exception.getStatus()
  : HttpStatus.INTERNAL_SERVER_ERROR; // <--- Error Prisma bukan HttpException!

Semua kegagalan constraint database (seperti duplikasi nomor kamar P2002 atau foreign key P2003) akan menghasilkan HTTP 500 Internal Server Error mentah dan mencetak error unhandled ke terminal log, bukan 400/409.
